# 表达形态与结构选择

同一段内容写成段落、分点、编号、表格还是流程图，不靠手感，按内容本身的形态判断。这份文档先总结人工拆解里的实际规律，再给出可照做的判断顺序。

固定章节和标题不得增加，形态调整只发生在小节内部。

## 一、从人工拆解里看到的规律

翻看历史拆解，段落和分点并不是混着来的，各有明确分工。

| 人工拆解里的写法 | 出现位置 | 说明 |
|---|---|---|
| 一段话概括范围、能力或背景 | 需求概述、算法提供、后端提供 | 一条主线讲完，不拆碎 |
| 并列清单分点 | 支持格式、图片输出规则、禁止引用清单、现状与目标、后端改造项 | 同级、无先后、逐条独立 |
| 有序编号 | 交互步骤、边界规则、判断优先级、配图条件 | 有先后、有优先级、按序执行 |
| 多对象同维度对比表 | 手动一键成片对比、图表类型对照、评估维度、优先级与验收指标 | 行是对象、列是维度 |
| 流程树与示意 | 算法链路、批量任务流程、入口结构 | 端到端、有分支、有兜底 |
| 截图 | 功能入口、页面状态、流程图示意 | 入口和界面用图更清楚 |

一句话概括：**能一句话讲清的写段落，并列的列出来，有先后的排编号，要比对的做表格，要走链路的画流程。**

## 二、五种形态各管什么

| 形态 | 适合的内容 | 判断信号 |
|---|---|---|
| 段落 | 背景、目标、总述、因果解释、单条结论 | 内容是一条逻辑主线，不是并列项 |
| 分点 | 并列枚举、规则清单、边界、异常清单、支持范围 | 三条以上同级项，彼此无先后 |
| 编号 | 操作步骤、流程环节、优先级、判断顺序 | 项与项之间有先后或轻重 |
| 表格 | 多对象同维度对比、参数取值集、指标口径、验收优先级 | 两个以上对象在多个维度逐格对照 |
| 流程图或树 | 端到端链路、分支与兜底、异步多阶段、前后端协作 | 有走向、有分支、有回退路径 |

分点解决"有哪些"，编号解决"先后做",表格解决"谁对谁",流程解决"怎么走",段落解决"为什么、是什么"。

## 三、判断顺序

落笔前先问三个问题，按顺序命中就停。

1. **是一条主线还是一条条并列？** 能一口气讲完的解释、背景、目标、总述写段落。
2. **并列项里有先后吗？** 没有先后用分点，有先后或有优先级用编号。
3. **是不是多个对象在同一批维度上对照？** 是就做表格，尤其是取值集合和指标口径。

都不是，再判断要不要流程图：

- 内容涉及触发、处理、结果可用或失败，且中间有分支、兜底或异步等待，用流程树或 Mermaid 表达走向，文字只补充要点。
- 只是入口和界面状态，用截图配一句说明。

## 四、量化触发条件

这几条可以直接当红线用。

- 单个要点超过 2 到 3 行还在往里塞并列信息，拆成分点或表格。
- 一句话里连续出现"并且、同时、另外、分别、包括"三处以上，多半该拆表格或清单。
- 出现"先……再……然后……最后"或"若……则……否则"，用编号或流程图。
- 同类对象两个以上、对比维度两个以上，做表格，别写成流水句子。
- 某类取值只有固定几种（形态、时长、格式、性别），列成表格或直接把取值写完。

## 五、按固定小节映射

| 固定小节 | 主形态 | 补充形态 |
|---|---|---|
| 前言 | 字段行与短段落 | 材料清单 |
| 版本信息 | 字段行 | 无 |
| 变更日志 | 表格 | 无 |
| 需求背景 | 字段清单 | 无 |
| 【功能入口】 | 段落 | 多个入口对比用表格；入口位置用截图 |
| 【新增功能】 | 建设内容用段落 | 流程简要说明用编号或流程树；特殊情况处理用分点 |
| 【算法功能】 | 能力与效果用段落 | 规则取值与指标口径用表格；大致流程用流程树；能力边界与实验清单用分点 |
| 【后端需求】 | 建设内容与前端配合用段落 | 模型能力与特殊情况处理用分点；多路径职责对比用表格 |

段落和结构不必平均用。判断标准是内容形态，不是篇幅。

## 六、常见错误

| 错误 | 问题 | 正确做法 |
|---|---|---|
| 把并列规则挤进一整段 | 关系被埋住，研发要自己拆 | 拆成分点或表格 |
| 每个字都拆成一句一条 bullet | 信息碎，读起来费劲 | 解释性内容合并成简洁段落 |
| 该有先后的写成无序分点 | 看不出执行顺序 | 改成编号 |
| 多对象对比写成流水句 | 有差异看不出来 | 做表格 |
| 链路和兜底只写文字 | 分支和回退看不清 | 补流程树或 Mermaid，文字只留要点 |
| 表格单元格塞长句 | 表格失去对照作用 | 单元格只放短结论，细节放段落 |
| 用形态填充凑长度 | 结构喧宾夺主 | 没内容就不加结构 |
